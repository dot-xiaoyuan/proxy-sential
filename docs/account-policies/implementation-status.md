## 当前实现

- 新增 `internal/policy`：账号身份有效区间、三周期过期、事件时刻冲突归责、跨会话设备去重、总数/手机/电脑独立配额。随机 MAC 或缺少稳定标识保持未知，覆盖不足时仍保留已确认数量下界。
- 标准身份适配补充用户组、产品、接入域、心跳/对账周期、设备类别和最近确认时间。原始身份观测按事件 ID 幂等保存；迁移文件为 `018_account_policies.sql`。
- 策略条件 AND/OR、范围豁免、北京时间生效时段、优先级和稳定 ID 排序；新建强制禁用、仅观测。实现配额试算接口及页面。
- 状态机保存违规轮次与阶段，重复评估不重复创建动作；持续条件在身份中断时重置，已成立轮次在数据未知时暂停阶段计时。人工确认与撤销采用独立权限。
- 账号动作复用现有签名发送、重试、熔断、影子准入和解除机制；可声明账号原生动作或逐会话动作，逐会话保留成功/失败状态。执行前重新读取身份；不回退到共享 IP 封禁。限速期间发现新会话时补建同一限制租约下的子动作。
- 历史应用重分类支持批次边界暂停、恢复、取消，取消保留已提交结果和游标，暂停期间仍固定原特征版本。
- 同步策略 OpenAPI、权限、前端类型及模拟数据。页面入口 `/policies`。

## 控制器契约与当前限制

控制器在 `action_mapping` 声明 `account_policy_v1: supported`，并声明 `account.notify`、`account.rate_limit`、`account.disconnect`、`account.disable_account` 或相应 `session.rate_limit` / `session.disconnect` 的实际动作名。没有声明的渠道或动作被阻止。停用账号不以强制下线模拟。

签名动作请求增加 `policy` 对象：`execution_id`、`lease_id`、`operation`、`rate_kbps`、`template`、`access_domain`。账号原生操作必须覆盖全部当前会话及有效期内的新会话；限速租约必须按仍有效的最严格限制合并，解除只撤销指定租约。逐会话控制器同样必须按租约及目标会话撤销，不能无条件解除该账号的所有限制。

上述租约能力仅由内置 HTTP 沙箱验证请求内容、幂等发送与解除，**尚未验证任何现场控制器实现**。原有通用网关不会因配置了旧的 `rate_limit` / `disconnect` 映射就自动获得新能力。

策略周期评估当前随数据库模式的动作 worker 运行；文件模式用于显式调用的开发回放和试算。风险触发配置可保存，但 `shared_access` / `explicit_proxy` 的输入明确返回 `risk_evidence_not_evaluated`，不会据此自动处置。
