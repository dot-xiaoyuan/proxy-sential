# ADR 0001: 使用标准事件层解耦采集后端

## 状态

Accepted

## 背景

防代理系统可能使用 Suricata、Zeek、AF_XDP、DPDK 或 pcap 作为采集后端。如果风险引擎直接依赖某个后端的字段，后期替换或并行验证会很困难。

## 决策

系统引入 Normalized Event 作为唯一业务输入。所有采集后端必须实现 adapter，将原始事件转换为标准事件。

## 后果

收益：

- 采集后端可替换。
- 可以做事件回放。
- 风险引擎更稳定。
- 后期可以 Suricata 与 AF_XDP 并行对比。

代价：

- 第一阶段需要额外实现 adapter。
- 部分后端特有字段需要通过 raw_ref 保留。
