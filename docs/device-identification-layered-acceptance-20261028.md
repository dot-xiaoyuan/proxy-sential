# 设备识别分层与新鲜输入诊断验收（2026-10-28）

## 实现范围

识别统一沿用“信号归属 → 精确查表 → 产品候选 → 字段定向规则 → 分维度裁决”。直接设备属性、旧发现观测和新流事实复用结构化证据接口；保留协议、字段、方向、来源族、事件引用、观测及失效时间和归属质量。产品类型与共享上网行为角色分别计算。本轮未增加主动探测、页面或存储组件。

- 精确型号、OUI、SNMP 企业号、DHCP 和服务目录提供候选，规则按字段和产品族定向运行；旧规则逐字段匹配，不跨字段拼接字符串。
- 品牌、产品族、型号、设备类型、系统分别保留依据及冲突。高置信冲突只影响对应维度，弱线索不能覆盖已确认值，同一观测多库命中不增加置信度。
- 候选最多 16 项、维度依据最多 48 项、每项引用最多 4 条；原文仍由权威事件保管。
- 沿用设备详情、列表和特征库现场覆盖页签；接口增加可选诊断字段，旧字段兼容。

统一接口列出 DHCP/DHCPv6、LLDP/CDP、DNS-SD/mDNS、SSDP、SNMP、HTTP/TLS、IPP、ONVIF、WS-Discovery、SSH/SIP、MQTT、CoAP、BACnet、RTSP、ARP/NDP、IEEE 1905。实际识别依赖可信归属和有效字段：HTTP/TLS/SSH/SIP 要核对服务端方向；ARP/NDP/1905 用于关联；RTSP 产品字段仍待接入；无新输入的协议明确显示缺口。UA、TLS 客户端指纹、TTL/TCP、端口和域名不独立确认硬件品牌、型号或路由器身份。

## 新鲜输入与存储边界

迁移 `197_recognition_fresh_observability.sql` 增加不可变 `recognition-fresh-cutoff`，仅在起点后首次接收的标准发现 receipt 上写紧凑诊断。没有历史 UPDATE、旧事实补写或重排队列；导入数据包与历史重算解耦，现场必须保持 `PROXY_SENTINEL_FINGERPRINT_HISTORY_BACKFILL` 不启用。

诊断分别记录接收、解析、归属、有效特征、当前事件贡献的候选及结论，以及处理中、无法归属、证据不足、冲突和错误。起点是标准发现事件接收，并不表示原始报文采集完整率。首次 accepted_at 不因重试改变；逐条保留超时标记和观察到的错误，但不声称具有每次尝试的完整日志。

后台观察每批最多 100 条，输入及已存结果合计最多 256 KiB，事务超时 5 秒。协议名最多 64 字节，身份引用字段总计最多 2048 字节；超界记 `diagnostic_limit`，不截断成另一个设备身份。归属要求唯一 MAC 和对应范围、事件时刻的租约；最多检查 2 个候选，复用现有 MAC 索引，不对索引列调用 lower。每分钟异步聚合最近 24 小时，页面请求只读取现成结果。

新增两个 partial index 分别支持待观察领取和新鲜窗口统计；每条 receipt 在写入、处理完成时维护索引，完成后退出 pending 索引，window 索引随 receipt 热历史生命周期退役。诊断和原 receipt 同步保留、归档，不另存原文。实际 PostgreSQL 行、索引增长与负载影响仍须用自然新输入测量。

job 的 processed_at 可能被更高 generation 覆盖，因此处理耗时是保守上界，**不能代替登录态 HTTP 逐事件查询可见时间**。5 秒目标及状态接口 P95 ≤500 ms、P99 ≤1 s 尚待现场实测，不能以本地回放、平均值或旧缓存宣布达标。

## 三路消费恢复修复（r7）

现场 DHCP、packet 和 handshake 仍停留在旧来源代次。定位到旧 search 步骤连续执行查询索引和风险特征两次 ClickHouse 请求：索引写入已提交但响应丢失时，恢复确认同时要求风险特征存在，而第二次请求可能尚未发送，因此会持续等待。不能通过盲目重发旧请求、标记完成或历史回填解决。

新片段为风险特征保存独立的持久确认点，仍复用原有有界 search worker。索引成功后才进入特征写入；特征恢复确认包括幂等风险唤醒；任一必要步骤未确认时不能释放片段。旧片段保留原格式与歧义状态。

新增 `ingest stream-cancel`，对已停止且持有本地/数据库来源租约的旧代次先预览再原子审计关闭。固定游标、片段状态、未读范围、记录数、字节数和 SHA256 形成紧凑清单，状态为取消未处理；已归档的旧片段、确认日志和原始来源保留。文件来源使用同 inode 硬链接保护原文，无额外原文副本；跨轮转缺代、锚点不唯一、来源被替换/改写、原始归档未确认或超出扫描边界时拒绝取消。当前文件追加不会移动已保存的截止点。新鲜续接仍走原有 prepare/shared-activate 审计流程，接口统计保留已关闭代次的历史缺口。

本地相关四包测试、Go 构建、vet 和 streamlog race 测试通过；回放包含响应丢失、中断恢复、旧格式兼容、禁止盲重发、禁止提前释放、压缩轮转、原文硬链接保护和范围改写拒绝。r7 发布、固定截止审计及新输入观察结果在执行后补充，不宣称 5 秒或容量已达标。
