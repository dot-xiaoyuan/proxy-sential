# 终端画像改版验收记录

## 发布

- 2026-09-21 部署至 `192.168.0.30`，版本 `2026.09.21-device-profile`，五个服务均为 active，部署就绪检查通过。
- 上一版本保留于 `/opt/proxy-sentinel/releases/2026.09.21-device-name-search`。发布脚本包含失败自动恢复上一版本的流程。
- 无新增持久化字段和数据库迁移；本次不修改风险评分、处罚及设备数量计算。

## 行为

- 新页面默认近期 24 小时，可切换全部历史。IP 第一列，名称、设备识别、MAC、最近观测和操作随后；账号及接入信息按列设置启用。
- 搜索、视图、时间、筛选及分页保存在 URL；详情返回保留筛选。可选列保存在浏览器，页面可见时每 15 秒刷新，失效页码回落到最后有效页。
- 缺失字段留空；确定信息优先，域名与 MAC 同品牌依据合并为次要线索。VMware 为独立虚拟化平台线索，可与操作系统并存。
- 详情使用名称和最近 IP 作为标题；名称证据位于设备识别，内部 ID 移至技术信息。
- `/devices` 可传 `view=recent|history`；省略 view 的旧客户端保留历史语义。近期范围排除过期和未来终端记录。
- 完整 IP 查询按地址精确匹配，近期查询只匹配窗口内 IP 观测或与窗口相交的账号会话。`ip_match` 按页批量读取，返回来源、时间及是否为最近 IP。计数和分页使用相同条件，筛选项不随分页变化。

## 验证结果

- Go store/controlplane 竞态测试通过。
- 独立 PostgreSQL 回放通过：时间边界、未来/过期记录、完整 IP、历史换绑、跨窗口会话、分页计数及筛选项范围。
- TypeScript 类型检查和生产构建通过；前端单元测试 14 项、Playwright 页面测试 8 项通过。
- 390×844、1280×800、1440×900 截图、DOM 样式探针及规范检查完成；未发现页面横向溢出，按钮和标签不压缩换行。
- 线上浏览器验证近期/历史切换、完整 IP 搜索和命中说明；结束时恢复近期 24 小时、空搜索。

现场抽样时，近期 24 小时为 58 个终端身份，全部历史为 134 个。搜索 `192.168.0.82`，近期命中 2 个、历史命中 8 个，其中 4 个最近 IP 已不同，页面显示历史命中时间。这些是终端身份关联数量，不是同时在线或物理设备数量；实时数据会继续变化。

测试日志、发布包、校验和、现场查询摘要和三视口截图保存在 `artifacts/device-profile-redesign-20260921/`。现场查询为只读，集成测试使用独立 PostgreSQL 容器，未向生产库写入模拟终端。
