## 现场原因

`10.157.2.191` 在终端列表按 IP 检索没有结果。184 只读核对显示：`mac:90:fb:5d:a7:40:4b` 在 `endpoint_entities` 和 `endpoint_inventory_lookup` 中仍有终端身份，但查找表的 `current_ip` 为空；该 IP 在 `device_address_leases`、`account_sessions` 中没有可用的精确关联记录。终端列表检索设备身份和已生成的地址关联，所以不会因新流中出现这个 IP 就自动返回该 MAC。新流中的握手和 TTL 是独立的流量观测；没有足够的归属证据时，不应把它写成当前 IP 与终端的确定关系。
