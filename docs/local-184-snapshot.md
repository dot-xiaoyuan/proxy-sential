# 184 数据快照与本地联调

开发数据来自 `root@222.204.3.184`。前端通过 Vite 同源代理访问本地 Go 后端，后端使用本地 PostgreSQL 和 ClickHouse。现场不安装、迁移或重启服务。

## 启动与日常修改

先启动 OrbStack，然后在仓库根目录执行：

```bash
make dev184-snapshot  # 只读获取新快照，首次导出需要数分钟
make dev184-up        # 首次恢复数据、执行本地迁移、构建并启动前后端
make dev184-status
```

前端地址是 `http://127.0.0.1:5173`，后端地址是 `http://127.0.0.1:18084`。登录名为 `dev-admin`，随机口令在受保护、已被 Git 忽略的 `data/dev184/runtime.env` 的 `DEV184_ADMIN_PASSWORD` 中。保留现场用户数据，额外创建本地开发管理员。

前端代码修改后由 Vite 热更新。后端修改后执行：

```bash
make dev184-restart
```

停止本地服务并保留数据：

```bash
make dev184-down
```

重新执行 `make dev184-snapshot` 和 `make dev184-up` 可切换到新快照。每个快照有独立的数据库目录，旧快照和旧数据库均保留。脚本不会覆盖已有的非空数据库。导出中断但 PostgreSQL 导出已经完成时，可用 `python3 scripts/local/dev184.py capture --resume data/dev184/snapshots/<UTC时间>` 继续导出；脚本会先验证归档及现场版本。恢复中断时，保留现场和本地文件，先检查错误及已完成步骤再继续，不直接重新导入叠加数据。

## 数据范围

快照位于 `data/dev184/snapshots/<UTC时间>/`，`data/dev184/latest` 指向最新完成的快照。`manifest.json` 记录来源、现场版本、传感器、采集起止时间、迁移账本校验、各文件 SHA256、大小和 ClickHouse 查询范围。快照跨数据库不具备同一事务的一致性，用于开发联调，不作为生产恢复备份。

- PostgreSQL 保留完整结构、迁移账本及账号、策略、当前画像、会话和其他业务表。大型 `identity_ip_mac_history` 只取最近 2000 个终端各两条历史；`device_signal_events` 和 `identity_ingest_batches` 只保留结构，省略原始历史数据。
- ClickHouse 标准事件取快照开始前六小时，每种类型最多 10000 条，总计最多 120000 条。保留最多 10000 条采集诊断、100000 条应用观测；活动统计取六小时的五分钟事实和七天的小时/天事实，每表有行数上限。
- 标准事件导入后，相关物化视图由本地 ClickHouse 生成。活动统计是独立抽样的现场统计，不能拿它与抽样事件总数做全量一致性或检测准确率验收。
- 快照使用真实时间，不平移到当前时间。放置数小时后，实时页面可能因窗口过期而显示较少数据；需要新鲜数据时重新获取快照。

这套流程保留真实字段与业务关系，适合页面、查询、接口和后端逻辑调试；全量历史、长期趋势与性能验收需另设数据范围。

## 本地隔离与配置

专用 Compose 文件为 `deploy/compose/snapshot.yml`，容器名带 `dev184`，PostgreSQL 端口为 `25433`，ClickHouse HTTP 端口为 `28124`。它与既有 30 日志回放工作流使用不同端口、容器和数据目录。

Go 后端在本机 Docker 中运行，容器网络设置 `internal: true`，仅能访问同一栈内的数据库，不具备外网路由。导入后关闭现场处置连接器、发现采集源、周期扫描、通知和行为上报通道，处置连接器改为影子模式。前后端只发布到 `127.0.0.1`。后端通过独立 Nginx 入口供主机访问；后端自身仅连接内部网络，数据库另外连接主机访问网络以支持本地迁移和测试。本地 realtime 读模型负责统计心跳和快照内的统计任务；不启动现场采集器、身份同步或现场风险处置进程。

前端配置写入已被忽略的 `frontend/.env.development.local`：

```dotenv
VITE_API_BASE=/api/v1
VITE_ENABLE_MOCKS=false
VITE_DEV_PROXY_TARGET=http://127.0.0.1:18084
```

若该文件已有其他配置，脚本先备份到 `data/dev184/`。代理变量支持 `.env`、`.env.local` 及 Vite 模式环境文件；命令行显式设置优先，显式空字符串关闭代理。

快照、数据库、口令、运行日志和二进制均在 Git 忽略目录内。不可将它们提交到仓库。`capture` 仅通过 SSH 执行主机与服务检查、迁移账本查询、`pg_dump` 和 SELECT/COPY 导出；压缩和文件写入发生在本地。
