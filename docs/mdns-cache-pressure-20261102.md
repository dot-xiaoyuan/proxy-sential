# mDNS 缓存满额准入审查（2026-11-02）

r39 的 20 分钟现场观察中，缓存从 2,643 增至 5,794 条；10,000 条和 8 MiB 限额均未触发拒留。新键在满额时仍会被拒绝，当前报文照常解析和记录，但后续跨报文关联可能缺少缓存依赖。

本地满额回放显示：暂时没有 SRV 指向的有效 A，仍可与晚到的同作用域 SRV 关联。多个服务也可共用目标主机。因此“当前没有 SRV 引用”不能证明 A/AAAA 可安全驱逐；本次不改变准入和回收语义。

新增 `retained_by_kind`，按 A、AAAA、PTR、SRV、TXT 记录当前缓存占用，与已有按类型拆分的拒留累计数一同判断容量压力。计数在准入、撤销和过期时更新，快照不扫描缓存；它不代表漏发现设备数。需等现场出现实际限额压力并核对报文分布，再设计有界替换及回退。相关 Go 测试、构建和 vet 通过；未在 184 造数或修改现场。
