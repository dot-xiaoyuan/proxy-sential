# NCU 认证关系处理边界

状态：2026-10-29 代码候选，尚未现场切换。本文定义本次改造的业务契约；测试和现场结果分别记录，不能以代码测试代替吞吐验收。

## 业务目的与权威数据

认证输入提供“来源、网络作用域、时间、IP、账号、会话以及可靠的设备关联”。共享行为检测用这些关系解释流量属于哪个账号，不能以认证 IP 冒充 DHCP 确认的物理设备地址。

- 持久收件箱负责原始接收、内容校验和恢复；身份事实提供可追溯的变化及窗口查询。
- `account_sessions` 保留现有会话读取契约。新鲜输入的消费者按会话键更新结果，保留下线、乱序和登录代次语义，不扫描整个账号库，也不另建一份当前身份表。
- `last_confirmed_at` 是来源确认时间，`updated_at` 是结果变化时间。设备中心、路由器认证绑定和共享设备档案不能靠不断重写行来维持身份有效性。旧应用写入的确认元数据通过同一行的 BEFORE 触发器维护新字段，便于分阶段切换和回退。
- `endpoint_entities` 保存设备实体和来源证据。认证处理不执行同步指纹/画像构建；实际设备证据变化通过现有持久识别任务更新展示。
- 设备画像和共享设备档案是派生展示。它们有自己的进度，不是认证关系写入的完成条件。

## 写入与事务

身份事实和消费位置保持原有原子提交。认证结果仍使用有界片段、事件数与字节数双重限制，保留租约代次和完成栅栏。设备实体事务与会话事务继续分开，避免把共享设备行锁持有到会话提交结束；本次不以盲目合并事务替代必要性审查。

认证专用路径取消设备画像的读取、构建和比较，也不运行无关的 DHCP/流量信号生成。包含通用设备事件的批次保留原路径，不能因为优化认证而丢失其他证据。

会话 upsert 只返回实际应用的变化，完全相同或过旧的重放不重新排入共享设备档案任务。会话关系迁移时，旧设备与新设备都必须失效。结果及这些失效请求在同一事务中提交；完成位置也只在结果成功后推进。

设备列表的会话游标只能看到会话最终所在设备，不能表示连续 A→B→C 迁移中离开的 A 和 B。因此只有真实关系迁移才写入 `identity_endpoint_invalidations`，按旧设备主键合并，不按消息保存任务。设备列表先刷新这些设备，再按领取的版本确认；新版本不会被旧刷新确认吞掉。每个设备至多一行，随设备删除级联退出；没有正文或历史副本。共享档案在查不到支持会话时明确清空旧账号字段，避免“任务处理了但旧关联仍残留”。

共享档案待办按业务主体合并：尚未领取的脏任务直接读取最新会话结果，不因同一主体的后续消息递增任务代次；已领取任务若遇到变化则保留新的代次，防止旧消费者完成时吞掉新变化。未变化的档案只完成任务、安排下一次自然过期检查，不重写档案和历史。缺失关联键仍可修复。

## 调度与历史边界

后台压力包含固定新起点后的就绪片段，包含已领取且正在处理的片段。索引按来源和首次接收时间定位最老任务，不读取正文或全历史。进程内共享每秒一次的压力探测，探测期间不持缓存锁。30 秒是后台让路阈值，不是新的业务新鲜度验收门槛。

派生承压或探测失败时，共享设备档案消费者全部让路；不得让主接收队列已经为零掩盖后续派生积压。已开始的业务事务仍按其预算结束，不强杀事务。

NCU 归档使用与认证派生相同的不可变接收起点，不再回退消费旧格式历史。旧归档仍是未处理状态，原文保留，不能计为完成。独立连接池必须继承新起点配置。历史取消审计应停止自动运行，保留不可变截止点、已完成的逐批审计和尚未完成的登记状态；这不恢复旧派生，也不删除证据。

## 数据库变更成本

迁移 201 为会话增加一个可空确认时间字段，不回填历史。确认时间的部分索引仅服务仍开放、已有来源确认时间的会话；收益是有效身份筛选不必解析大 JSON，代价是开放会话确认变化时维护索引。结束会话退出该索引，原有会话保留规则不变。

就绪队列增加 `(sensor_id, accepted_at)` 索引，每个未完成片段增加一个索引项；原有终态触发器删除就绪键时一并退出，不复制正文。初次创建索引需要扫描已有表，应在授权切换窗口检查锁等待和耗时，不将这次扫描改成日常任务。

设备实体识别触发条件忽略认证会话状态和接入维度变化；设备识别证据、登记变化及原有小时级活跃变化仍会触发。认证维度继续保存在实体/会话中，设备列表自身更新不依赖识别任务。

## 验证与发布边界

必须验证：重复无改写、乱序不复活下线会话、关系迁移同时刷新两端、领取期间的新变化不丢失、确认时间与写入时间分离、过期检查仍调度、固定起点排除旧任务、已领取任务仍计入压力、事务失败不推进完成。

两万用户的有界 Go 回放验证身份语义和批次边界，不能作为 PostgreSQL 容量证明。临时表 SQL 校验只验证实际 SQL 合并和队列语义，不造现场业务数据、不应用迁移、不做现场造数压测。

完整现场切换涉及 NCU 物化服务，以及读取确认时间/执行档案任务的控制面、识别、设备列表服务。它超出此前“仅切换 NCU 物化服务”的现场授权。应先完成候选包和验证，再获得这几个必要消费者的定向切换授权；不切换发现投影、统计、采集或全站 current。

现场验收分别记录接收、身份事实、会话结果、下游档案和新输入归档的进出量、未完成数量、最老接收时间、错误和资源等待。用持续真实输入验证队列趋势及恢复，不以某一瞬间为零、取消历史或短时样本宣布长期容量达标。保留旧应用目录和服务覆盖文件，数据库迁移向前兼容，回退不重新启动已放弃的旧处理。
