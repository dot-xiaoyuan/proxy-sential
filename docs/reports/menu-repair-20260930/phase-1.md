# 第一阶段：判断与操作缺陷修复

2026-09-30，本次任务的文件修改在原有工作区基础上完成。

- 事件检索支持 10 分钟、1 小时、24 小时、7 天、30 天；协议、传感器、校区和详情返回条件保持在 URL。
- 图表按数据 key 跳转，聚合“其他”不产生单值查询；IP 数量与设备数量分开命名。
- 风险等级统一为正常、可疑、高风险、极高风险；人工确认代理保持独立结论。
- 风险规则读取 `/rules/status` 的实际能力，不提供热重载按钮。Flow 追查也移除了错误调用 reload 的“加入影子审计”。
- 样本列表、导出和标注使用稳定 sample_id；同一运行的不同对象不串联标注。旧标注只有完整运行的证据能唯一定位样本才继承，歧义不计入真值。
- 样本详情读取受控历史目录，校验快照身份和证据引用。缺失、过期、解析错误均明确反馈；确定性结论禁用，允许需补数据。
- 新增 FileStore 标签读取，使文件模式列表与离线评估共用匹配算法。按时间点比较最新标注，兼容时区写法。
- 修复移动端筛选、按钮裁切、连接器列表操作区域的内部溢出；新增样式均位于 index.css。

验证：新增接口与证据回放测试通过；Go 全量测试通过。最终联合验收包含前端 36 项单元测试、类型检查、生产构建及 113 项 Playwright 回归，详见总验收记录。

本阶段后续工作已在第二、第三阶段完成：菜单拆分、工作台与影子评估内容完善。规则热重载继续由服务端保持 disabled，这是当前真实能力。策略编辑器已有未提交重构，本次配额文案修改保留在工作区，并单独收录 workspace-overlap.patch。
