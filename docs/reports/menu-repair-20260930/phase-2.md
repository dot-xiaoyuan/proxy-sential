# 第二阶段：菜单重组与页面拆分

已完成六类一级菜单与所有子菜单的路由归属、读取权限、父菜单展开和刷新选中状态。

- `/actions` 复用策略执行、审批、撤销和动作观察组件；接入配置保持 `/settings/actions`。
- `/policies/exceptions` 独立加载校园例外；`/settings/security` 只加载用户权限。
- `/settings/sources` 包含采集诊断、基础设施接入、主动发现和发现任务；`/discovery` 保留路由识别、发现记录和设备发现结果。
- `/activity` 的 applications/access/technical 分别组织应用访问、访问分析与技术指纹；活跃风险 IP 已移至工作台。
- 旧 ingest、动作、安全、风险和复核入口保留查询参数跳转。IP 详情采用合法来源菜单；直接打开归属事件检索。
- 返回地址必须符合已登记站内路由；拒绝外站、非登记路径和递归 IP 返回地址。
- 当前标签页按需请求；连接器失败不阻断动作记录，用户失败不阻断校园例外。
- 共享观察和账号复核保持独立筛选与游标。只对已有明确 ID 提供业务跳转，不以同 IP 合并案件。

验证：四种角色的直接访问及样本写权限、两个故障隔离场景、旧链接查询保留、详情菜单归属均通过 Playwright。标签页、筛选、分页进入 URL；完整联合验证结果见总验收记录。
