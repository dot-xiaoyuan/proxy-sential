## 设备发现核对与修复

现场数据库已有 92 个终端实体。Suricata 最新约 2 MB 日志中，连续两次采样均有 192.168.0.93 的实际流量（390/3920、217/3567 条）；不是人工合成流量。

192.168.0.93 已有 DHCP/IP-MAC 历史，关联 `mac:6c:1f:f7:5d:9a:2c`。设备页面按 IP 搜索却返回零条，原因是 PostgreSQL 的设备列表搜索漏查 IP 历史/会话；FileStore 支持 IP 的语义与数据库实现不一致。

先增加真实 PostgreSQL 回归，确认修复前零条失败；再增加 EXISTS 匹配 IP 历史和账号会话，确保筛选在分页前执行，不因重复观测增加行数。回归及竞态测试通过后更新 r2。现场设备页面按 192.168.0.93 搜索返回一条对应终端。

页面厂商为 Ugreen Group Limited，依据 MAC 厂商，不等同于整机品牌；型号和系统证据仍不足。账号未绑定符合本轮暂缓认证接入的范围。

实时入库检查点已推进至部署之后，Suricata、DHCP、mDNS 等正常读取。终端画像最近时间来自身份/设备证据更新，不应把它误读成每个流量包的实时最后出现时间；本轮未改该语义。生态线索仍存在 endpoint_id 未归属问题，未声称完整画像识别已完成。
