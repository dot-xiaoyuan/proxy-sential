# 共享证据策略接入记录（2026-09-15）

本轮在本地接通共享证据、策略试算与周期评估，尚未部署生产，也未开放共享账号处置。

## 已实现

- 通过 `PROXY_SENTINEL_SHARED_ACCESS_CONFIG` 或 `--shared-access-config` 登记共享采集来源，样例为 `examples/shared-access/sources-lab.json`。固定格式 `shared-access-sources/v1`，明确传感器、来源、园区、接入域和新鲜度。空配置保持证据不足；配置损坏、重复、来源范围冲突会阻止服务启动。
- 配置不补写历史事件范围。原事件缺少园区或接入域时仍不能归责；事件自行声明可信无效。
- PostgreSQL 按 IP、传感器、园区和接入域选择最新窗口，FileStore 保留开发回放实现。最多 10,000 个范围，超过上限返回不完整错误，不截断后假装完整。
- 先选择最新窗口，再判断命中。旧正例不会覆盖新负例或新不完整窗口。账号其他接入范围缺失、未登记时不能得出完整恢复结论。
- 试算返回 `shared_evaluation`，包含三态结果、事件时账号、设备下界、信号、时间窗口、规则与来源配置版本以及原始事件引用。
- 周期策略使用同一共享评估入口，仍复用优先级、范围、豁免、持续条件和状态机。数据库错误、身份不确定和证据过期维持未知，不视为恢复。
- 本阶段共享证据只进入观测模式：输入评估、动作创建与发送前校验分别阻止处罚。直接使用 `shared-` 证据绕过策略授权也被拒绝；解除动作保留已有恢复语义。
- 试算页面展示共享依据和身份范围，文案区分“存在共享依据”“当前未命中”“证据不足”，不把信号差异宣称为已确认的下游设备数。界面限制共享模式为观测，后端另有独立约束。
- OpenAPI 与前端类型已同步，沿用现有策略读取权限，不增加绕过权限的新风险入口。

## 2026-10-16：共享确认仅记录链路

新增 `PROXY_SENTINEL_SHARED_OBSERVATION_ENABLED`，默认关闭。开启后，采集入库按 IP 合并 PostgreSQL 待办，控制面独立运行两个有界 IP 观测 worker、一个网关地址解析 worker 和一个低优先级归档 worker；全局 `--read-only=true` 继续阻断人工执行接口。内置 `builtin:shared-access-observe` 不进入综合 action worker，状态存入独立 `shared_observation_executions`，不会创建处置动作或通知。策略页可见，修改和执行入口均拒绝访问。

握手采集保留原摘要，并提供逐特征时间、五秒桶、TCP 流和序号及载荷产生的去重键；完整 ClientHello 才产生 JA3。UA 型号与协议栈共现仍使用既有确认阈值。每桶保留最多 200 个主体，逐主体最多 288 个特征样本，全桶最多 32768 个样本；主动裁剪、特征溢出、解析失败和内核丢包均进入覆盖事实。单个 IP 的完整输出不能替其他 IP 证明覆盖；内核丢包等影响范围不明的损失阻止整段确认。旧摘要不具备逐特征时间时仅作线索。

EasyMesh 完整接入快照也进入独立任务。L2 事件先按网关 MAC 留持久化待办，只有事件时及当前地址归属一致、且有效租约覆盖完整窗口时才关联出口 IP；转发报文的源 IP 不作为网关归属依据。同时间的离开事件优先，空 BSS 快照只清除对应 BSS，过期成员不计数。旧关联摘要和未重组分片无法证明完整覆盖。

共享账号判定版本更新为 `shared-access/v5`。明确型号会统一大小写和品牌前缀，避免同设备不同浏览器的 UA 格式差异被计成两台设备；通用 Android、模拟器等标识不计入硬件型号。既有确认门槛保持不变。

新增迁移：PostgreSQL `142_shared_observation_recording.sql`、ClickHouse `044_shared_observation_events.sql`。没有改写已应用迁移，也不回填历史命中。部署配置样例见 `examples/shared-access/sources-184-observe.json.example`、`examples/shared-access/observe.env.example`；启用前按现场只读预检核对采集范围、实例、身份注册及映射生效时间。

身份查询只读取目标 IP、精确来源范围及事件窗口附近的事实和快照成员，不再每轮加载全网七天快照。快照成员索引只在观测开关开启后随新快照事务生成；旧快照不自动视作可用。`health_bridge_id` 将映射绑定到身份桥健康区间，新迁移不倒填健康证明。身份桥失败、超过 60 秒的心跳缺口、待消费身份变化、范围冲突、会话换代均阻止命中，恢复后需要新的完整窗口。

采集覆盖心跳单独保存来源、实例与测量区间；没有候选流量时，也能区分采集正常和停产。来源映射按配置版本保存，认证事件只唤醒受影响 IP，完整认证快照只唤醒对应范围已有的当前共享 IP，身份桥健康变化也会触发复核。失败不确认待办。

同一事务写入观察、策略状态、决策记录和任务确认。决策键包含策略版本、账号、接入范围、会话代次和证据版本；重复处理不新增，证据或覆盖证明变化另留版本。过期只记“证据已过期”，不写“已恢复”。批次首次开始时间作为保守的处理时延起点，重试不向后移动；它早于标准事件入库，不用于宣称现场五秒验收通过。

`GET /policy-decisions` 支持 `trigger=shared_access`、`account_id`、`ip`、`observation_id`、`result`、`from`、`to`、`limit`、`cursor`。结果为 `matched / insufficient / expired`，按 `(evaluated_at, decision_id)` 倒序游标分页，游标绑定筛选条件和首次分页时间。共享记录固定为 `mode=observe`、`planned_action=disconnect`、`delivery_status=not_sent`。共享页的“策略触发记录”默认显示命中；共享详情可跳转到关联评估。
